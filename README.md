# GSAP Motion Demo

> Interactive Front-End animation demo focused on motion, depth and micro-interactions.

## ✨ Overview

This project is an interactive Front-End demo created to explore how animations can enhance the perception and usability of a modern web interface.

The goal is not to add motion for the sake of animation, but to create a more fluid, dynamic and engaging user experience while maintaining a clear visual hierarchy.

## 🎯 What the demo showcases

- 🎬 Sequenced GSAP timelines
- 🌀 Smooth continuous animations
- 🖱️ Mouse-based parallax effects
- 🎛️ 3D hover interactions
- ✨ Micro-interactions
- 📐 Layered depth and movement
- ⚡ Smooth transitions and easing
- 📱 Responsive interface

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- GSAP (GreenSock Animation Platform)

## 💡 Animation approach

The animations are designed around a simple principle:

**Motion should support the interface, not distract from it.**

The demo combines different animation techniques to create hierarchy and depth:

- Timeline sequencing for coordinated entrances
- Different movement speeds to create a parallax effect
- Rotation and translation for 3D depth
- Hover feedback to make interactions feel more natural
- Continuous background motion to add subtle dynamism
